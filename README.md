# Warframe Builds

В этом репозитории собраны гайды и билды по игре `Warframe`.

## Структура репозитория

- **Основные гайды** по конкретным варфреймам хранятся в корне репозитория (например, `Висп.md`, `Воруна.md`).
- **Побочные гайды**, которые не являются гайдами по отдельным варфреймам, хранятся в папке `Побочные гайды`. К ним относятся материалы по Рэйлджеку, Некрамехам, компаньонам, общим системам игры и другим смежным темам.

## Что внутри

- Билды под соло и под игру в пати.
- Варфреймы, оружие, спутники и вспомогательные элементы.
- Короткие автономные `.md`-гайды, которые можно читать отдельно друг от друга.

## Принципы работы

- Упор на реальные игровые сборки, а не на теорию ради теории.
- Черновая база и структура билдов формируются с помощью ИИ. Правила и инструкции для генерации описаны в файле [AGENTS.md](AGENTS.md).
- После создания ИИ, билды просматриваются, правятся и тестируются человеком.
- В репозитории лежат финальные человеко-проверенные версии. Все файлы пишутся как автономные инструкции: без ченжлогов, без ссылок на другие гайды и без следов переписки.
